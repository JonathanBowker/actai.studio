# Advanced Analytica Discovery Pack

This pack runs a ten-question discovery interview about something you want to make or a business process you want to improve. It takes about twenty minutes and works by voice or text. Several people in your business can each run a separate session.

## ChatGPT

1. Unzip the pack. Create a ChatGPT Project (or custom GPT), paste `AGENTS.md` into its instructions, and upload the whole pack. For a custom GPT, also follow `platform/chatgpt-custom-gpt-config.md`.
2. Start a new conversation and say: `start discovery`. You can use voice for the interview.

## Claude

1. Unzip the pack. Create a Claude Project, paste `AGENTS.md` into its project instructions, and upload the whole pack.
2. Start a new conversation and type: `start discovery`.

Answer in your own words. Do not include sensitive personal information. At the end, turn voice off and type `package my answers`. The assistant will produce one markdown document in a code block. Save it using the filename shown, then email it to `jonathan@advancedanalytica.co.uk` or place it in the shared folder Advanced Analytica gave you.

Nothing is sent automatically. You decide whether to return the completed file.
