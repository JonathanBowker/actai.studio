# ChatGPT Project setup

PROJECT_NAME: Advanced Analytica Discovery
VOICE_CAPABLE: yes
CONVERSATION_STARTER: start discovery

1. Create a ChatGPT Project named `Advanced Analytica Discovery`.
2. Paste the complete contents of `AGENTS.md` into the Project instructions field.
3. Upload the whole unzipped pack as Project files.
4. Start a new Project conversation with `start discovery`.

Voice may be used for the interview. The final trigger `package my answers` must be typed.
