# Website V4 reference

Derived references from `../Website_V4-01.png`. The original design remains unchanged.

## Grid

- Desktop artboard: 1920px wide.
- Outer gutters: 80px.
- Content width: 1760px.
- Columns: 12 equal columns.
- Column gaps: 20px.
- Centred headings: columns 3 through 10.
- Main split layouts: columns 2 through 11.

## Typography

See `00-typography-direction.png`.

- Principal headings: MG12 Bold, 90px, 1.05 line-height, -0.025em tracking.
- Supporting copy: MG12 Bold, 35px, 1.3 line-height, -0.025em tracking.
- Body copy: MG12 Medium, 25px, 1.3 line-height, -0.025em tracking.
- Bold body copy: MG12 Bold, 25px, 1.3 line-height, -0.025em tracking.
- Labels: MG12 Bold, 20px, zero tracking.
