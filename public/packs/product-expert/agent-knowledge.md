# Product Expert Agent knowledge

## What the agent does

A Product Expert Agent answers product-related questions using only approved course content. It can cite or link to the relevant lesson, keep knowledge separate between white-label brands and refuse unsupported questions instead of inventing an answer.

## Problem it removes

Users waste time searching course libraries or asking support teams for answers that already exist. Answers become inconsistent when people rely on memory or use material from the wrong brand.

## How it fits a business

The agent sits inside the learning experience and uses the authenticated user's brand and permissions to select the correct knowledge base. Celebrity Cruises and Royal Caribbean can share the same technical framework while retaining separate content, instructions and reporting.

## What it needs

It needs representative course content, source formats, content ownership and update rules, platform integration details, authentication requirements, approved answer behaviour and clear rules for citations, refusals and escalation.
